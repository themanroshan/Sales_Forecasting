# End-to-End Sales Forecasting & Demand Intelligence System

## Project Overview

This project develops a Sales Forecasting and Demand Intelligence System using historical retail sales data.

## Features

- Exploratory Data Analysis
- Time Series Forecasting
- SARIMA
- Prophet
- XGBoost
- Anomaly Detection
- Product Segmentation
- Streamlit Dashboard

## Tech Stack

- Python
- Pandas
- NumPy
- Scikit-Learn
- Prophet
- Statsmodels
- XGBoost
- Streamlit
